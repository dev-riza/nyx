# Nyx AI Assistant 

A locally-hosted voice assistant running on Raspberry Pi 4.

## Features
- 🎙️ Wake word detection ("Nyx")
- 🧠 Powered by Cerebras gpt-oss-120b
- 🔊 Natural TTS via Piper
- 🌍 Bilingual — English & Russian
- 💾 Persistent memory across sessions
- 🔍 Web search for real-time info
- ⚡ Fast speech-to-text via Groq Whisper

## Stack
- Speech-to-Text: Groq Whisper
- AI Brain: Cerebras gpt-oss-120b
- Text-to-Speech: Piper TTS
- Wake Word: faster-whisper
- Hardware: Raspberry Pi 4
